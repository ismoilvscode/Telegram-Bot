# Telegram Personal Bot Project

Ин боти шахсӣ бо истифода аз китобхонаи **aiogram 3** сохта шудааст.

### Функсияҳо:
1. **Командаи /start:** Салом алейк ва менюи асосӣ.
2. **Анкета:** Саволҳои кӯтоҳ барои корбар.
3. **Қабули сурат:** Бот метавонад расмҳоро қабул ва коркард кунад.
4. **Кнопкаҳо:** Истифодаи Reply Keyboard ва Inline Keyboard.

### Тарзи запуск:
1. Клон кардани репозитория.
2. Насби китобхонаҳо: `pip install aiogram python-dotenv`.
3. Сохтани файли `.env` ва илова кардани `BOT_TOKEN`.
4. Иҷрои бот: `python main.py`.
